# Breast Cancer Classification Streamlit App

## a. Problem statement

The goal of this project is to compare multiple supervised machine learning classification models on the Wisconsin Diagnostic Breast Cancer dataset and deploy the results through an interactive Streamlit web application. The app allows a user to upload test data, choose a trained model, and view model performance metrics and predictions.

## b. Dataset description

Dataset: Wisconsin Diagnostic Breast Cancer (WDBC)

Source: UCI Machine Learning Repository

Task type: Binary classification

Target variable: `diagnosis`

- `0`: Benign
- `1`: Malignant

The dataset contains 569 records and 30 real-valued input features computed from digitized images of fine needle aspirate samples of breast masses. These features describe cell nucleus characteristics such as radius, texture, perimeter, area, smoothness, compactness, concavity, concave points, symmetry, and fractal dimension.

The raw dataset is stored in:

```text
breast+cancer+wisconsin+diagnostic/wdbc.data
```

The cleaned dataset generated by the training script is stored in:

```text
data/wdbc_clean.csv
```

## Model observations

| ML Model Name | Observation about model performance |
| --- | --- |
| Logistic Regression | Strongest overall by AUC and F1. Feature scaling helps it separate benign and malignant cases well. |
| Decision Tree | Lowest recall and F1 among the models, which suggests a single tree is less stable on this dataset. |
| kNN | Good performance after scaling, but slightly below Logistic Regression and Random Forest. |
| Naive Bayes | Simple and fast with strong AUC, but lower F1 because its independence assumption is not fully true for these correlated features. |
| Random Forest | Tied for best accuracy, highest precision, and highest MCC, but recall is slightly lower than Logistic Regression. |
| Overall Winner for your dataset? | Logistic Regression, because it has the highest AUC and F1 while tying for best accuracy. |
